# Two-Criterion Rubric (`complete` and `actionable`)

The earlier three-criterion rubric (`intent_clear`, `context_sufficient`, `consistent`) suffered from overlapping criterion boundaries and false blocks caused by overloading `consistent` with abrupt topic-switch detection. We simplify the rubric to two independent, positive-polarity criteria aligned with the two failure modes the hook aims to prevent: `complete` (preventing accidental mid-thought submissions, bare noun phrases, or empty attachments) and `actionable` (preventing missing references, unchosen options, or contradictory constraints that would send the agent in the wrong direction).
